<h1 align="center">MIM-Dashboard</h1>
<h3 align="center">Magic Internet Money Dashboard</h3>
<p align="center">
  <em>A complete local web dashboard for Bitcoin Core node management.</em>
</p>

A self-hosted web interface to monitor, manage, and interact with your Bitcoin Core node. Connects via RPC and ZMQ — no third parties, no external dependencies. Just you and your node.
